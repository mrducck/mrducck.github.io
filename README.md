# Mewb

Personal portfolio: 3D models, pixel art, game UI and the plugins behind [Reefed](https://reefed.fun).

Plain HTML, CSS and JavaScript with no build step, served by GitHub Pages.

- `index.html`: the whole site
- `css/style.css`, `js/main.js`: styles, gallery filters and the image viewer
- `img/work/`: gallery images (`<name>-sm.webp` thumbnails and full-size `<name>.webp`)
